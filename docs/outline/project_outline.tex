% ------------------------------------------------------------
\subsubsection{Drugs@FDA}
% ------------------------------------------------------------

Drugs@FDA contains \textbf{51,864 product records} across
\textbf{29,377 applications}. The product table contains only
\textbf{8,388 distinct drug names} and \textbf{3,355 distinct
active-ingredient strings}, showing substantial reuse across products.
Consequently, \textbf{DrugName + ActiveIngredient} provides a more
appropriate starting point for entity linkage than DrugName alone.

The dataset is strongly imbalanced. Among applications,
\textbf{78.3\% are ANDAs}, \textbf{20.1\% NDAs}, and
\textbf{1.7\% BLAs}. Among 194,004 submission records,
\textbf{85.6\% are supplemental}, while \textbf{99.4\%} have submission
status AP.

\begin{sloppypar}
Three attributes exceed 30\% missingness:
\texttt{ApplPublicNotes} (\textbf{99.99\%}),
\texttt{SubmissionsPublicNotes} (\textbf{99.83\%}), and
\texttt{ReviewPriority} (\textbf{41.73\%}). The first two are optional
regulatory note fields and are therefore populated only in exceptional
cases. Missing \texttt{ReviewPriority} values cannot be explained by
submission type alone: missingness remains high for both original
submissions (\textbf{49.5\%}) and supplements (\textbf{40.4\%}).
Overall, ReviewPriority consists of \textbf{49.3\% Standard},
\textbf{5.8\% Priority}, \textbf{3.2\% other codes}, and
\textbf{41.7\% missing values}.
\end{sloppypar}

% ------------------------------------------------------------
\subsubsection{EMA Medicines}
% ------------------------------------------------------------

The EMA dataset contains \textbf{2,746 medicine records} and
\textbf{39 attributes}, with no duplicate rows. It is predominantly
composed of human medicines (\textbf{85.6\%}). Medicine status is also
imbalanced: \textbf{68.5\% are currently authorised},
\textbf{15.4\% withdrawn}, and \textbf{10.4\% represent withdrawn
applications}. Fifty medicine names occur more than once, again showing
that names alone do not uniquely identify entities.

Twelve EMA attributes exceed 30\% missingness. Most of this is
\textbf{structural rather than erroneous}. Veterinary attributes are
inapplicable to human medicines, while refusal, withdrawal, suspension,
and rolling-review dates exist only if the respective regulatory event
occurred. Two more broadly applicable attributes require closer
inspection: \texttt{Opinion adopted date} is \textbf{46.2\% missing},
and \texttt{Revision number} is \textbf{30.2\% missing}.

% ------------------------------------------------------------
\subsubsection{openFDA NDC Directory}
% ------------------------------------------------------------

The openFDA National Drug Code (NDC) Directory contains product
listing information submitted to the FDA by drug labelers.
The dataset was downloaded in JSON format and converted to CSV.
It contains 138,209 product records and 7,682 distinct active
ingredient entries. The listing includes both FDA-approved and
unapproved products. Inclusion in the directory does not imply
FDA approval.

Attributes: product NDC, brand and generic names, active ingredients,
manufacturer, dosage form, route, marketing start date, marketing
category, and application number. Marketing start date is not
necessarily the approval date.

Across the 10 selected columns, 113,976 of 1,382,090 values are
missing, which is approximately 8.25\%, assuming the remaining
columns have no missing values. The missing values by column:

\begin{itemize}
    \item \texttt{brand\_name}: 21,716 (15.71\%)
    \item \texttt{generic\_name}: 3 (less than 0.01\%)
    \item \texttt{active\_ingredients}: 2,521 (1.82\%)
    \item \texttt{manufacturer}: 28,052 (20.30\%)
    \item \texttt{route}: 23,596 (17.07\%)
    \item \texttt{application\_number}: 38,088 (27.56\%)
\end{itemize}

\subsection{Why enough entities are likely contained in multiple datasets}
% ============================================================

Exact normalized \texttt{name + active substance} matching currently
identifies \textbf{428 shared FDA--EMA entities}, while normalized-name
overlap reaches \textbf{752}. The required
\textbf{$\geq 1,000$ shared entities} has therefore not yet been
demonstrated. The third dataset should consequently provide substantial
overlap with FDA or EMA and preferably contain active-substance
information together with additional shared regulatory attributes.
